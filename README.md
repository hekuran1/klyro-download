# Klyro Android download site
Static pages served by GitHub Pages: `/` (landing) and `/download/`. The signed APK (package app.klyro.mobile, versionCode 4) is the asset of GitHub Release v1.0.0, not stored in Git. For https://klyro.wiki add a `CNAME` file containing `klyro.wiki` and set the custom domain once DNS points to GitHub Pages.
